# Task 002: Filter Expensive Orders

Given a list of orders, write Python code to filter orders where amount is greater than 100.

Example input:

orders = [
    {"order_id": 1, "amount": 50},
    {"order_id": 2, "amount": 150},
    {"order_id": 3, "amount": 200}
]

Expected output:

[
    {"order_id": 2, "amount": 150},
    {"order_id": 3, "amount": 200}
]
