# Task 004: Calculate Mean by Group

Given a list of records with group labels and values, write Python code to calculate the mean value for each group.

Example input:

records = [
    {"group": "A", "value": 10},
    {"group": "A", "value": 20},
    {"group": "B", "value": 30}
]

Expected output:

{
    "A": 15.0,
    "B": 30.0
}
